What it means for the build
  • The flat-plate direction is right: no accent bars, no glass, no drop shadows.
  • Real mismatch is hierarchy: the reference keeps map and money together in the top-left so "where am I / how much" reads in one glance; ours splits them across two corners.
  • Second mismatch: the reference treats the weapon as a picture, ours as a string, which is why the ammo line has to carry the weapon name too.
